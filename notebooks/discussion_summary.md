# 유사도 정의 / 마이닝 결정 기록

## 데이터 실측 (2026-09-19)

- `GLAMI-1M-dresses-train.csv`: 29,350 rows, unique image_id 26,326
- item_id는 이미지당 정확히 1개 (item_id 29,350 : image 26,326) — 같은 이미지가 geo별 다국어 리스팅으로 여러 item_id에 중복 등장하는 구조. "같은 item_id 제외"는 **no-op**으로 판명 (아무것도 안 걸러짐)
- 대신 막아야 했던 대상(동일 상품의 색상 변형 등)은 서로 다른 image_id로 존재 → `name` 문자열 완전일치 그룹으로 대체 제외 (1,407그룹 / 4,153장 해당, 2,000장 서브셋에서는 22쌍 제외)
- 이번 baseline은 26,326장 중 무작위 2,000장 서브셋으로 진행 (시간 제약, 2026-09-19 확정). 마스크 추출은 기존 결과를 건너뛰므로 필요시 나중에 확장 가능

## Threshold 스팟체크 (mask IoU, top-K=50 후보 중 샘플)

IoU 구간별로 anchor-positive 이미지 쌍을 6~8개씩 뽑아 육안 비교. 결과 리뷰 페이지: https://claude.ai/artifact/NLHFRKPEBHbBc9RunsNf6k

| 구간 | 관찰 |
|---|---|
| 0.1–0.4 | 명백히 무관 (미니 vs 롱드레스, 브라 vs 원피스 등) |
| 0.4–0.6 | 뒤섞임 — 실루엣 비슷한 것도 있으나 길이/핏이 다른 경우多 |
| 0.6–0.7 | 대체로 납득되나 기장이 어긋나는 애매한 사례 존재 |
| 0.7–0.8 | 일관되게 설득력 있음 — 기장·소매·핏이 잘 맞음, 색상·패턴·브랜드는 다름 |
| 0.9–0.95 | 매우 좋음 — 같은 실루엣, 명백히 다른 상품 |
| 0.95–0.97 | 여전히 다른 상품 (24쌍뿐), 실루엣만 매우 유사 |
| 0.97–1.0 | **동일 사진의 재등장** 지배적 — 같은 모델·포즈·드레스가 다른 image_id로 중복 |

**확정 threshold: 하한 0.70 / 상한 0.97** (2026-09-19)

- 하한 0.70: 0.6–0.7 구간의 애매함을 배제하고, 0.7부터 일관되게 실루엣이 닮은 지점을 채택
- 상한 0.97: 그 이상은 동일 사진 재등장(near-duplicate)이 지배적이라 컷

적용 결과: candidates 99,978 → mined_pairs 86,114 (`data/pairs/mined_pairs.csv`), anchor 1,906/2,000이 최소 1개 이상의 positive 확보 (94개 anchor는 이 서브셋 안에서 0.70 이상 후보가 없어 anchor로는 사용 불가 — 다른 anchor의 positive로는 여전히 등장 가능).

## 실루엣 정의 문구 정정

원안 "색상+실루엣, 소매/넥라인/패턴/기장 제외"는 mask IoU 구현과 불일치 (IoU는 소매·기장을 포함하는 외곽선 전체 비교). 정의를 구현에 맞춰 "실루엣 = 마스크 외곽선 전체"로 정정 (README 반영 완료). 추가 가공(소매 제거 등) 없이 단순 mask IoU 그대로 사용하기로 확정.
